# Brand assets

Artwork for the NiFiMCP README, repository social preview and organization avatar. These files are
documentation; they are not part of the Python package or the offline kit.

| File | Use |
|---|---|
| `readme-banner-aviation.jpg`, `readme-banner-dark-aviation.jpg` | README hero, 1600 x 800, light and dark: the graphite aviation N with engraved M C P lettering, red and green position lights, a white beacon and a cyan data channel |
| `nifimcp-aviation-n.jpg` | the hero artwork on its own |
| `readme-banner.png`, `readme-banner-dark.png` | the earlier bronze banners, kept so existing external links keep working |
| `how-it-works.png` | the preview stages and the roadmap stage, 1600 x 940 |
| `social-preview.png` | GitHub repository social preview, 1280 x 640 |
| `org-avatar.png` | GitHub organization avatar, 1024 x 1024 |
| `logo-ink.svg`, `logo-white.svg` | the compact mark (faceted N, straight cyan diagonal, two position lights); the SVGs are canonical |
| `logo-ink.png`, `logo-white.png` | 1024 px transparent rasters rendered from the SVGs |
| `wordmark-ink.svg`, `wordmark-white.svg` | the wordmark with outlined lettering; canonical |
| `wordmark-ink.png`, `wordmark-white.png` | 1400 x 306 transparent rasters rendered from the SVGs |
| `favicon.svg`, `favicon-16.png`, `favicon-32.png` | site icons, rasters rendered from the SVG |

The artwork is an original NiFiMCP illustration. The aviation cues (position lights, beacon) are a
design motif; no aircraft manufacturer mark or endorsement is implied.

The NiFiMCP name, symbol and wordmark identify this project and its maintainer. The Apache License 2.0
covers the code and documentation in this repository; it does not grant rights to use the name or
artwork in a way that suggests endorsement. Reasonable use to refer to the project (a link, a blog
post, a conference slide) is welcome.

The wordmark lettering was set in Familjen Grotesk, IBM Plex Sans and JetBrains Mono and outlined;
their SIL Open Font License texts are kept in `LICENSES/`.
