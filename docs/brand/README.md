# Brand assets

Artwork for the NiFiMCP README, repository social preview and organization avatar. These files are
documentation; they are not part of the Python package or the offline kit.

| File | Use |
|---|---|
| `readme-banner.png`, `readme-banner-dark.png` | README hero, 1600 x 800, light and dark |
| `how-it-works.png` | the preview stages and the roadmap stage, 1600 x 940 |
| `social-preview.png` | GitHub repository social preview, 1280 x 640 |
| `org-avatar.png` | GitHub organization avatar, 1024 x 1024 |
| `logo-ink.*`, `logo-white.*` | the symbol, vector and 512 px transparent raster |
| `wordmark-ink.*`, `wordmark-white.*` | the wordmark as used on nifimcp.com |
| `favicon.svg`, `favicon-16.png`, `favicon-32.png` | site icons |

The NiFiMCP name, symbol and wordmark identify this project and its maintainer. The Apache License 2.0
covers the code and documentation in this repository; it does not grant rights to use the name or
artwork in a way that suggests endorsement. Reasonable use to refer to the project (a link, a blog
post, a conference slide) is welcome.

The wordmark lettering was set in Familjen Grotesk, IBM Plex Sans and JetBrains Mono and outlined;
their SIL Open Font License texts are kept in `LICENSES/`.
