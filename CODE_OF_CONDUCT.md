# Code of conduct

This project welcomes anyone who wants to make Apache NiFi easier to operate with AI.

## Expected behavior

* Be respectful and assume good intent.
* Keep discussion about the work: code, evidence, documentation and user problems.
* Give and accept technical criticism with specifics.
* Protect other people's data. Never post real flows, credentials, customer names or private logs.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, sexualized content, threats, doxxing, and sustained
disruption of discussions.

## Enforcement

Maintainers may edit or remove contributions and restrict participation for behavior that breaks this code.
Report concerns privately to the maintainer, [Lloyd Clark](https://github.com/FlightDeckAI), through the
contact form at [nifimcp.com/#contact](https://nifimcp.com/#contact). Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
