# Decisions log

Departures from, and resolutions of, the project's design specification (an internal document, not published). Newest last.
Where the specification's prose and schemas conflict, the stricter authority boundary wins.

| # | Date | Decision | Reason |
|---|---|---|---|
| D1 | 2026-10-29 | Target stays **Apache NiFi 2.12.0** (Apache download page rechecked at build start: 2.12.0 and 1.28.1 are the only listed releases). Lab image pinned by digest `sha256:6f7f2840…f28ad`; runtime reports Java 21.0.12.1. | Spec: do not silently retarget. |
| D2 | 2026-10-29 | REST contract taken from `swagger.json` inside the pinned image's `nifi-web-api-2.12.0.war`. The container does not serve `/nifi-docs/swagger.yaml` (redirects to the UI). | Version-matched contract required; legacy doc page is 1.28.0. |
| D3 | 2026-10-29 | MCP **Python SDK 2.3.0** (current stable v2), low-level `mcp.server.lowlevel.Server` so the ten tools publish the exact contract JSON Schemas. The SDK's default OpenTelemetry middleware is removed. | Exact schemas; no telemetry. |
| D4 | 2026-10-29 | HTTP client is `httpx2` 2.16.0, already a dependency of `mcp` 2.3.0. `trust_env=False`, `follow_redirects=False`, explicit CA, hostname verification on. | Keep dependencies few. |
| D5 | 2026-10-29 | NiFi 2.12.0 requires `Read /data/{component}` for both `POST /provenance` and queue listing (documented security annotations; confirmed in the lab). The observer identity therefore holds data-read on its scope. NiFiMCP has **no route** to content, FlowFile attributes or replay, so the metadata restriction is enforced in code. Identities without data-read get partial capability. | Spec: enforce metadata restriction even when the credential could read content. |
| D6 | 2026-10-29 | Provenance search on 2.12.0 indexes only `EventType, FlowFileUUID, Filename, ProcessorID, Relationship` by default and cannot filter by process group. Queries use one exact selector plus a bounded time window and `maxResults`; NiFi's own per-scope provenance policy limits visibility; events outside the configured scope are dropped **before** evidence is created and the count is reported as a gap. `indexed_attribute` selectors require an operator-approved name that also appears in the instance's search options. | Narrowest scope the 2.12.0 API can express. |
| D7 | 2026-10-29 | Unknown provenance query IDs return HTTP 500 on 2.12.0. NiFiMCP never sends an ID it did not create (owned-query registry). | Lab observation. |
| D8 | 2026-10-29 | FlowPlan `type_id` is the fully qualified processor class; ports use `nifi:InputPort` / `nifi:OutputPort`. Connections whose source is a port use the pseudo-relationship `port` (schema requires a non-empty relationship). | Schema minLength 1; unambiguous catalog keys. |
| D9 | 2026-10-29 | `scope_id` values are operator-configured aliases that map to process group IDs. A model cannot add scopes. | Spec: model cannot switch origins, credentials or allowed groups. |
| D10 | 2026-10-29 | No tool accepts host-written hypotheses (the frozen contract has no such field). Reports state that host interpretation lives in the host transcript, not in NiFiMCP evidence. Server-generated hypotheses are labelled `hypothesis` and carry limitations. | Contract is the public boundary. |
| D11 | 2026-10-29 | `get_flow_health` and `inspect_unmatched` accept an optional interval (schema); when omitted, the default 60-minute window ending now is applied and recorded in `limits_applied`. Maximum 24 hours enforced in code. | Stricter reading of "bounded interval". |
| D12 | 2026-10-29 | In NiFi a component-specific policy replaces the inherited one, so the lab bootstrap adds the lab admin to every scoped policy it creates. | Lab observation; affects lab only. |
| D13 | 2026-10-29 | On NiFi 2.12.0, `DELETE /provenance/{id}` returns 200 but only cancels the query: the finished query stays readable by the same user until NiFi's own expiration (about 30 minutes). `DELETE` of a queue listing request really removes it (later GET is 404). NiFiMCP records provenance cleanup as `delete_acknowledged`, reports gap `NIFI_RETAINS_CANCELLED_QUERY`, and never reuses the query. | Observed in the lab; reported honestly instead of claiming removal. |
| D14 | 2026-10-29 | The secure lab requires a client certificate at the TLS layer, so unauthenticated clients are refused before HTTP. Bearer-token files are supported by the adapter but the lab qualifies client-certificate identities only. | Lab design; token auth is covered by transport tests, not by a native NiFi login. |
| D15 | 2026-10-29 | NiFi 2.12.0 connection status snapshots carry endpoint names but not IDs; queue-to-destination links come from the scope's flow definition. | Lab observation. |
| D16 | 2026-10-29 | Raw live responses are kept only as operator-local `raw_observation` artifacts (0600) so citations can be re-verified. They are never exposed as MCP resources or included in exports. | Preserve raw input hashes separately from redacted outputs. |
| D17 | 2026-10-29 | The cluster half of A21 runs against a **real** disposable two-node NiFi 2.12.0 cluster with ZooKeeper (`scripts/cluster_topology_probe.py`). Both nodes share one lab server certificate, so a single node identity is seeded in the user and policy providers. The simulated cluster test remains as a fast regression only. | A mocked NiFi is not a native pass. |
| D18 | 2026-10-29 | Package metadata names the author as FlightDeckAI without a personal email; README services paragraph links the FlightDeckAI GitHub organization until a services page with a verified inquiry path exists. | Do not publish personal contact data or an unverified inquiry route. |
| D19 | 2026-10-29 | The public repository lives in a dedicated GitHub organization, `nifimcp/nifimcp`, with the registry name `io.github.nifimcp/nifimcp` and PyPI project `nifimcp`. Package metadata, commits and the README name Lloyd Clark (GitHub `FlightDeckAI`) as founder and maintainer through the GitHub no-reply address only. Services are a separate commercial path linked from the README and nifimcp.com. | A project-named organization outlives any one account; the maintainer stays visibly attached without publishing a personal inbox. |
| D20 | 2026-10-30 | The PyPI project is `nifimcp-server`: PyPI rejected `nifimcp` as too similar to the unrelated `nifi-mcp` (its comparison ignores separators). The command, import package, repository and registry name stay `nifimcp`. | A name PyPI will not register is not a name. |
| D19 | 2026-10-29 | The public repository is exported from the committed tree with no private history; private-only files are listed outside version control, raw host transcripts are replaced by a sanitized transcript, raw logs stay under `evidence/**/raw/`, and absolute workspace paths in evidence become `<repo>`. | Keep internal planning material and raw evidence out of the public repository. |
| D20 | 2026-10-29 | MCP Registry `server.json` uses server version `0.1.0-rc.1` (semver, as the registry recommends) and package version `0.1.0rc1` (the PyPI version). Schema `2025-12-11`. | Registry sorting expects semver; the package version must match PyPI exactly. |
| D21 | 2026-10-29 | Provenance and bulletin results never count or describe what was dropped for being outside the scope. Every provenance result carries the same `EVENTS_OUTSIDE_SCOPE_DROPPED` statement, so its presence reveals nothing; unreadable bulletins are counted only when their component is in scope or unknown. Found by the independent review. | A model must not learn whether out-of-scope activity exists. |
| D22 | 2026-10-29 | Labels for hidden values (filenames, oversized values) are HMAC-SHA-256 keyed per session, not plain hashes. | A plain hash lets anyone confirm a guessed value. |
| D23 | 2026-10-29 | Raw live responses rotate oldest-first (500 per session) instead of counting toward the 200-artifact session limit, and `keep_raw_observations: false` turns them off. | Long live sessions stalled after about 100 calls. |
| D24 | 2026-10-29 | Offline (demo and bundle) default windows end at the bundle's collection time, not the current time; `STATUS_OUTSIDE_INTERVAL` makes a result partial. Updates D11 for offline sources. | A bundle report otherwise silently dropped all bulletins. |
| D25 | 2026-10-29 | The unused `GET /connections/{id}` and `GET /processors/{id}` were removed from the allowlist (16 to 14 endpoints). | Smaller surface; nothing called them. |
| D26 | 2026-10-29 | Registering the same bundle again is idempotent; a different bundle for an already registered scope is refused with the artifact ID to remove using the new `nifimcp unregister`. | Duplicate scopes broke every later command. |
| D27 | 2026-10-29 | Second independent review: `get_capabilities` and resource listings no longer show raw responses or stored oversized results (their sizes could reveal out-of-scope activity) and list at most 50 artifacts; `EVENT_LIMIT_REACHED` is decided after scope filtering; bundle provenance is scope-filtered before the event limit; `${EL}` and `#{parameter}` references are never masked. | Close the remaining side channels the review found. |
